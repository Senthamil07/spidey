SENTHAMIL SELVAN PORTFOLIO — VERCEL DEPLOYMENT

The original HTML design is preserved. No music has been added. The only deployment setup is the Vercel configuration file.

DEPLOY:
1. Extract this ZIP.
2. Open https://vercel.com and sign in.
3. Choose Add New -> Project. You can import a Git repository, or use Vercel's supported deployment workflow/CLI for this folder.
4. If deploying with Vercel CLI, open a terminal in this folder and run:
   npx vercel
5. Follow the prompts. For production deployment run:
   npx vercel --prod

This is a static HTML site; no framework or build command is required. Ensure index.html is at the project root.

NOTE: The background image is loaded from its existing external Unsplash URL, unchanged from the source HTML.
